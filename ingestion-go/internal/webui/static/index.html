Selecciona una partida para ver sus estadísticas.

Generar datos

Envía partidas al sistema desde tu navegador. Cada ejecución usa identificadores nuevos, así que se puede repetir sin reiniciar nada.

Verificación

Ejecuta la suite de 37 comprobaciones: 8 casos de prueba contra los resultados calculados a mano, 17 eventos inválidos con su error exacto y 12 comprobaciones del ciclo de vida de una partida.

Enviar evento

Elige una plantilla del contrato o escribe un evento a mano. Las plantillas inválidas muestran el error que el sistema debe devolver.

API pública: /v1/matches · /v1/stats · /v1/rejections · /healthz
